## Research

### Natural Language to Linear Temporal Logic

**MSc thesis | Khalifa University | Successfully defended**  
**Supervisor:** Prof. Jamal Bentahar

*A Comparative Study of Encoder-Decoder and Decoder-Only Large Language Models for End-to-End Natural Language to Linear Temporal Logic Translation*

I investigated how model architecture affects the reliability of translating natural-language requirements into **Linear Temporal Logic (LTL)**, where a small change in logical structure can change the meaning of an entire specification.

- Curated and validated a **31,794-example dataset**, and fine-tuned **six instruction-tuned models** across encoder-decoder and decoder-only architectures using **LoRA-based parameter-efficient fine-tuning** under matched experimental conditions.
- Developed a multi-layer evaluation framework combining normalised exact match, syntactic validity, **bounded finite-trace semantic agreement**, paired statistical comparisons, and operator-, complexity-, and error-based analysis.
- Built an **end-to-end research interface** connecting requirement extraction, proposition abstraction, model inference, validation, and cross-model comparison.

**A key finding:** Five models exceeded **97% normalised exact match**, yet deeper analysis revealed materially different failure patterns behind similar aggregate scores.
